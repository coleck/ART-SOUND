# ART/SOUND

**ART/SOUND** — веб-приложение для подбора музыкального сопровождения к произведениям искусства. Система анализирует визуальные характеристики картин и аудиохарактеристики музыкальных композиций, после чего формирует рекомендации по их сопоставлению.

Проект разрабатывается как прототип цифровой системы для художественных галерей и выставочных пространств.

## Возможности

### Для посетителей
- Просмотр опубликованных произведений искусства.
- Переход к странице картины по QR-коду.
- Прослушивание музыкальных композиций, связанных с произведением.

### Для администратора
- Добавление и редактирование картин.
- Загрузка музыкальных композиций.
- Анализ изображений и аудиофайлов.
- Автоматическое формирование музыкальных рекомендаций.
- Просмотр и управление рекомендациями.
- Одобрение и отклонение предложенных сочетаний.
- Публикация произведений.
- Генерация QR-кодов для доступа к страницам картин.

## Запуск проекта

Для запуска необходимы:
- Docker
- Docker Compose

### 1. Клонирование репозитория

```bash
git clone <URL-репозитория>
cd picture_sound
```

### 2. Настройка переменных окружения

В корневой директории необходимо создать файл `.env`:

```env
POSTGRES_PASSWORD=your_password
FRONTEND_URL=http://localhost:8080
```

Не публикуйте файл `.env` и реальные пароли в репозитории.

### 3. Запуск приложения

```bash
docker compose up -d --build
```

После успешного запуска приложение будет доступно по адресам:

- Основная страница: http://localhost:8080
- Панель администратора: http://localhost:8080/admin
- API документация: http://localhost:8000/docs

### 4. Остановка приложения

```bash
docker compose down
```

Команда останавливает контейнеры, не удаляя данные PostgreSQL из Docker volume.

## Тестирование

Для проверки backend используется pytest.

Запуск тестов из директории `backend`:

```bash
pytest
```

Основные автоматизированные тесты расположены в `backend/tests/`. Они проверяют работу API, сервисов, загрузку файлов, рекомендации и основные сценарии взаимодействия компонентов системы.

В проекте также присутствуют дополнительные тестовые и вспомогательные скрипты.

## Хранение данных

PostgreSQL используется для хранения информации о произведениях искусства, музыкальных композициях, характеристиках файлов и рекомендациях.

Загруженные изображения, аудиофайлы и сгенерированные QR-коды хранятся отдельно от базы данных.

Для локальной разработки используется директория `media/`, которая подключается к backend через Docker volume.

## Ограничения проекта

ART/SOUND является учебным прототипом. Результаты анализа и сопоставления изображений с музыкальными композициями носят экспериментальный характер и не являются объективной оценкой художественного произведения или музыкальной композиции.

Перед использованием проекта в публичной среде необходимо настроить аутентификацию администратора, ограничить доступ к API и проверить права на публичное воспроизведение музыкальных материалов.

## Статус проекта

Проект находится на стадии разработки. Реализованы основные компоненты backend и frontend, работа с базой данных, загрузка файлов, формирование музыкальных рекомендаций и публичный доступ к опубликованным произведениям через QR-коды.
